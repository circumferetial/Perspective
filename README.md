# Perspective

一个**实验性的**几何推理库（.NET 11 / C#），尝试把精确符号计算、定理规则链与外部判定器
粘合成可验证、可解释的推理链。

> **请先降低预期**：这不是自动解题器。它目前只在少数经过手工形式化的真题上验证过，
> 大量情形会返回 `Unknown` 或直接报"不支持"。构造与降维仍需要人或外部模型提案，
> 机器负责严格验收。

## 设计取向

- **严格优先**：结论走三态严通道（真/假/未证），不把近似当证明；
- **可解释**：规则只记录结构化证明记录，解释文本由独立层渲染；外部判定器的黑箱步骤单独标注；
- **集成而非重造**：化简/判定/求解尽量交给成熟库（AngouriMath、Z3，SymPy 可选），
  本项目负责契约、验证与组合；
- **诚实降级**：能力之外的输入明确返回"不支持/未证"，不静默猜测。

## 当前能力（实验性）

| 方向 | 说明 |
|---|---|
| 射影/仿射规则 | 极线极点、La Hire、切点弦、调和点列、Pascal、Brianchon 等若干条 |
| 圆锥曲线 | 分类、主轴、参数化、二次型限制到直线 |
| 精确计算 | 双轨标量、有理函数恒等式、实解集代数 |
| 反解/综合 | 割线范围、定点/定值、一元/有理目标极值 |
| 约束与量词 | 前序范式 AST、假设⇒结论、不等式证书 |
| 外部输入 | 构造注入（外部提案 + 机器验收）、归约提案验证 |

## 已验证的例子（回归测试内）

这些题目是在测试里逐条手工形式化并验证的，**不代表同类题都能自动完成**：

- 2023 新高考Ⅰ 22：轨迹方程；矩形周长严格大于 3√3（证书链）
- 2022 新高考Ⅰ 21：弦斜率、三角形面积
- 2022 浙江 21：最大距离、线段长度最小值
- 2022 全国乙 20：动直线过定点
- 2020 上海 20：求参数、夹角余弦、向量点积与取值范围

## 快速开始

```bash
dotnet build Perspective.slnx
dotnet test  Perspective.Tests                 # 主回归，无原生依赖
dotnet test  Perspective.Oracle.Z3.Tests       # 实代数判定器（含原生库）
dotnet test  Perspective.Sympy.Tests           # SymPy 子进程（需 python + pip install sympy）
```

## 现状与局限

项目处于早期阶段，接口与文档都可能大幅变动。已知局限包括：量词交替只支持特定形状、
超越函数与一般不等式组不保证、辅助构造仍依赖外部提案、性能未做系统优化。
欢迎 issue 指出错误或提供反例——**错误的结论比"没做出来"更值得报告**。
