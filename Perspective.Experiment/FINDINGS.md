# 实验：子空间/楔积的统一表述是否更好写？

分支：`experiment/subspace-representation`（不合并，仅作评估）

## 试了什么

把点/线统一成三维向量空间里的**子空间**：

- 点 = 1 维子空间（齐次三元组）；
- 线 = 对偶空间里的 1 维子空间（同一三元组的对偶包装）；
- **两点连线**与**两线交点**都用一个 `Wedge`（叉积）完成；
- 关联关系 = 对偶配对 `l·p = 0`；
- 极线 = 二次型矩阵对点的作用（同一个线性代数）；
- 线系/曲线系 = 线性组合（线性系）。

代码见 `Perspective.Experiment/Program.cs`（约 120 行，含演示）。

## 观察

**好处**

1. **Meet/Join 合并为一个原语**：交点与连线不再各写一套（对偶自动出现）。
2. **对偶免费**：点与线只是"同一对象的两侧"，不需要为"线变换要用逆转置"之类的规则单独记忆（虽然实现里仍存在）。
3. 概念上更接近教科书：关联、线性系、二次型统一在"子空间 + 双线性型"下。

**代价**

1. **类型安全要靠包装**：`Vec3` 裸用会点线混用，需要 `Point`/`Dual` 之类包装，样板并未减少。
2. **圆锥曲线与度量没有被统一**：极线只是二次型作用；距离/角度仍需额外结构（内积），这是"结构"而非"约束"。
3. **对解释层不友好**：`Dual(...)`、楔积的中间量对用户不如"过 A、B 的直线"直观；可读证明仍需另一套叙述。
4. **二维平面几何收益有限**：现有 `HPoint`/`HLine` 已经是同一表示，只是命名与类型不同；重构收益小于风险。
5. 高维/三维/自动对偶才是它的主战场（平面里 `Gr(2,3) ≅ P²*` 让一切"看起来"平凡）。

## 结论

**不在主线重构。** 若未来出现以下需求，再引入 `Subspace` 层：

- 支持三维/高维几何（点=1维、线=2维、面=余维1，真正需要统一）；
- 需要自动对偶/通用关联推理（如把"定理"与"对偶定理"自动配对）；
- 需要把"约束"统一成线性方程组（线性系的一般化）。

当前主线保留 `HPoint/HLine` + 齐次坐标 + `Matrix3x3` 群作用 + Erlangen 门控：
它已经是这套思想在二维的轻量投影，且对解释层更友好。

## 顺带记录：空间 vs 约束

- 空间之间是**结构差异**（射影 = 做商；仿射 = 选无穷远超平面；欧氏 = 加内积），不是单调"加约束"；
- 真正对应"约束"的是**对象**：点/线/曲线是 Grassmannian/线性系中的元素，"过五点的圆锥曲线"就是线性系。

## 追加：条件演化（ConstraintLadder）

从"最一般的对象"逐条加约束，观察对象如何被约束到唯一：

**直线（系数空间 3 维，射影 2 维）**

| 约束数         | 解空间维数  | 结果                   |
|----------------|-------------|------------------------|
| 0              | 3（射影 2） | 所有直线               |
| 1 个"点在线上" | 2（射影 1） | 过该点的直线束（线系） |
| 2 个"点在线上" | 1（射影 0） | 唯一一条直线           |

**圆锥曲线（6 系数／射影 5 维）**

- 过 4 点 ⇒ 1 维线性系 C(λ)=C1+λC2（整族都过 4 点）；
- 再加第 5 点 (1,1) ⇒ λ*=−1/6 被唯一确定，得到的曲线过全部 5 点；
- 数值验证：λ=0,±1 的成员都过 4 点（det 随 λ 变化）。

**结论**：这就是"约束演化"的精确形式——**加条件 = 在线性系里切一刀**；
几何里"点/线/曲线"不是被"造"出来的，而是从一般对象 + 约束条件里选出来的。
和主线代码的对应：`Conic.Pencil` 是线性系；`FactBase` 的条件/事实就是约束；
Proposer/Verifier 里的"归约提案"本质上也是选择一个约束子空间。

## 追加：结构阶梯（StructureLadder）

同一批共线四点，在不同变换群下测量"长度 / 线段比 / 交比"：

| 变换                | \|AB\| | \|CD\| | \|AB\|/\|CD\| | 交比 |
|---------------------|--------|--------|---------------|------|
| 恒等                | 1.414  | 2.828  | 0.5           | 1.5  |
| 相似（旋转+缩放 2） | 2.828  | 5.657  | 0.5           | 1.5  |
| 仿射（剪切）        | 1.803  | 3.606  | 0.5           | 1.5  |
| 射影（M₂₀=1/5）     | 1.179  | 1.122  | **1.05**      | 1.5  |

**结论**：长度只在相似/等距下保持（同比缩放）；线段比在仿射下保持；交比在射影下保持。
这就是 Erlangen 分层的可计算版本——**"空间"不是随便选的，而是由允许的变换群决定的**。

**与"加条件"的对照**：

- 加条件（ConstraintLadder）= 在线性系里选更小的子空间（对象变小）；
- 换群（StructureLadder）= 改变"什么算不变"（结构变强/变弱）。
  两者正交：一个约束对象，一个约束可观测的不变量。

## 追加：三维子空间 + Pascal = Plücker 线性依赖

**三维统一（GrassmannExperiment）**

- 点 = 4 维向量；线 = 两点楔积的 Plücker 6 元组；平面 = 三点楔积的对偶 4 向量；
- **Plücker 关系 p01·p23 − p02·p13 + p03·p12 = 0** 对任意两点连线恒成立（是恒等式，不是约束）；
- 关联判定与 join 是同一个楔积：`p∧a∧b` 为零 ⇔ p 在 a,b 连线上；
  平面通过三点、点落在平面上同样是配对/楔积；
- 结论：**"哪些性质是直接有的"**——关联、join/meet、Plücker 关系都是线性代数的恒等式，
  不需要额外假设；**"哪些没有"**——长度、角度需要额外内积结构（见结构阶梯）。

**Pascal = Plücker 关系（实验数值验证）**

- 圆的有理参数化取六点 P1..P6；三组对边交点 X=P1P2∩P4P5、Y=P2P3∩P5P6、Z=P3P4∩P6P1；
- 计算得 `det[X;Y;Z] = 0`（精确 0）：三点共线 ⇔ 齐次坐标 3×3 行列式为零；
- 于是 Pascal 定理在"本质描述"里就是**一条线性依赖/Plücker 关系**，可以被算出来而非假设；
  进一步用零空间（叉积）得到 Pascal 线并验证 Z 在线上。
- 这正是"定理搬到这边"的指导意义：先问"这条定理对应哪个楔积恒等式/线性依赖"，
  再决定它属于"白送的性质"还是"需要额外结构的性质"。

## 勘误与修正（2026-11-23，由用户代码审查发现）

1. **`Join` 的 P23 分量笔误**：原写作 `a.Z*b.W - a.Z*b.W`（恒 0），应为 `a.Z*b.W - a.W*b.Z`。
   之所以示例没暴露：初始两点 a、b 的 Z 分量都为 0，且 P02/P12 也恰为 0，恒等式"碰巧"成立。
   → 已修复；并新增两项自检：一般位置点（Z≠0、W≠0）逐分量与手算对照 + Plücker 恒等式检查。 **教训**
   ：演示用例必须含"一般位置"样本，否则特殊值会掩盖笔误。

2. **ConstraintLadder 维数口径**：原打印把线性维数（nullity）与射影维数混在一个数字里，
   现改为「线性维数 k（射影维数 k−1）」，避免误读。

3. **第 5 点求解的除零边界**：原代码直接 `-(v1/v2)`，假设 v2≠0；若第 5 点落在 C2 上则 v2=0。
   现用齐次参数 (λ1:λ2) 求解：v2≠0 → 非齐次 λ*；v2=0 且 v1≠0 → (0:1)，唯一曲线是 C2； (v1,v2) 全零 → 条件未进一步约束。演示中同时跑了非边界点
   (1,1) 与边界点 (2,−1)（在 C2 上）。

## 追加：P1 四点曲线系里的特征退化（2026-11-23）

从"过 4 点的 1 维圆锥曲线系" C(λ) = C1 + λ·C2 出发，解 det(C1 + λ·C2) = 0 得到退化成员。

**行列式与根**：取 C1 = 单位圆、C2 = 线对 (x+y−1)(x+y+1)，
det(C1 + λ·C2) = −(8λ² + 6λ + 1) = −(2λ+1)(4λ+1)，根 λ* = −1/2、−1/4（外加 λ=∞ 的 C2 本身）。

**3 组退化线对**（恰好对应 4 点两两配对的全部 3 种方式）：

| λ    | 退化圆锥曲线 | 两条直线      | 配对               |
|------|--------------|---------------|--------------------|
| −1/2 | −2xy = 0     | y=0、x=0      | {p1,p3} 与 {p2,p4} |
| −1/4 | (x−y)²−1 = 0 | x−y=1、x−y=−1 | {p1,p4} 与 {p2,p3} |
| ∞    | (x+y)²−1 = 0 | x+y=1、x+y=−1 | {p1,p2} 与 {p3,p4} |

**自极三角形**：3 组对边的 3 个交点 D1=(0,0)、D2=∞(1,1)、D3=∞(1,−1) 构成整族曲线共同的自极三角形——
两两关于 C1、C2 共轭（uᵀCu = 0 全部严格成立）。以 {D1,D2,D3} 为基，C1 与 C2 **同时对角化**
（非对角元全为 0），整族曲线都变成对角矩阵。

代码：`Perspective.Experiment/DegeneratePencil.cs`。

## 追加：P2 Cayley-Klein——用圆环点造欧氏几何（2026-11-23）

从射影平面"自上而下"：在无穷远直线 ℓ∞ 上钦定圆环点 I=(1,i,0)、J=(1,−i,0)，
欧氏几何的概念全部塌缩成纯射影关系。

**圆 = 过 I, J 的圆锥曲线**：一般圆锥曲线在 I 处取值 = M00 + 2i·M01 − M11，
过 I,J ⟺ M00 = M11 且 M01 = 0，正是圆的方程条件。两圆至多 2 个实交点，另外 2 个恒为 I、J（Bézout 2×2=4）。

**垂直 = 交比 (P,Q;I,J) = −1**：两线无穷远点 P,Q 的交比为 −1（调和共轭）⟺ 垂直。
等价于 l1ᵀΩl2 = 0（Ω=diag(1,1,0)），与 `GeometryAudit.ArePerpendicular` 的点积判据完全等价（4 组用例全部吻合）。

**角度 = Laguerre 公式**：θ = (1/2i)·ln(l₁,l₂;l_I,l_J)，交比是单位复数、幅角 = ±2θ。
数值验证：45°、30°、90°、60° 四组角度全部精确还原。角度是交比（射影不变量）的对数。

**根轴 = 两圆相减**：两圆方程相减消去 x²+y²，剩下的线性方程即根轴（与 `Conic.RadicalAxis` 一致），无需开方。

**度量 = 绝对形 Ω 的二次型**：Ω = diag(1,1,0)（圆环点对），对偶 Ω* = adj(Ω) = diag(0,0,1)（无穷远直线）。
距离平方 = (P−Q)ᵀΩ(P−Q)，与 `Metric.DistanceSquared` 一致。欧氏度量不是额外结构，而是绝对形的二次型。

全程不调用 Sqrt / 点积公式，只用交比、圆锥曲线矩阵与 diag(1,1,0)。
代码：`Perspective.Experiment/CayleyKlein.cs`。

## 追加：P3 Veronese 超平面视角 + Brianchon 对偶（2026-11-23）

**Veronese 嵌入 ν₂: RP² → RP⁵**：(x,y,z) ↦ (x², xy, y², xz, yz, z²)。
在这个 5 维射影空间里，圆锥曲线就是普通线性超平面（6 维系数向量），
"点在圆锥曲线上"和"点在直线上"一样，只是 6 维内积等于 0。

- **二次型 = 6 维内积**：单位圆系数向量 (1,0,1,0,0,−1)，对任意点 p，
  ν₂(p) 与系数向量的内积恒等于圆锥曲线二次型值 pᵀCp（4 组用例全部一致）。
- **过 5 点定圆锥曲线 = 解线性方程组**：5 个点的 Veronese 向量构成 5×6 矩阵，
  解空间维数 = 1，单位圆系数向量恰在解空间中。二次的圆锥曲线在 RP⁵ 里只是超平面，
  所以求过点曲线是线性问题。
- **对偶圆锥曲线 C\* = adj(C)**：单位圆 C\* = diag(−1,−1,1)。切线满足 lᵀC\*l = 0，
  非切线不为 0（4 组用例验证）。圆锥曲线既是点的轨迹，也是切线的包络，点线互换靠 C\* 完成。

**Brianchon 定理（Pascal 的对偶）**：外切于单位圆的六边形（6 条切线作边），
3 条主对角线 V1V4、V2V5、V3V6 共点。验证：系数矩阵行列式 det[D1;D2;D3] = 0（精确 0），
且 D3 严格过 D1∩D2。Pascal（内接 → 对边交点共线）在点线对偶下自动变成 Brianchon
（外切 → 主对角线共点），同一套机器无需改底层逻辑。

代码：`Perspective.Experiment/VeroneseBrianchon.cs`。

## 技术备注（2026-11-23 验证发现）

1. **AngouriMath 的虚数单位**：字符串 `"I"` 被解析成**符号 I**（I²=I²），不是虚数单位；
   必须用 `new ExactScalar(0.0, new System.Numerics.Complex(0,1))` 隐式转换构造（得到精确 i，i²=−1）。
   `ExactScalar.FromFormula("I")` 会抛 `CannotEvalException`（I 不可数值化）。
2. **符号名陷阱**：`ExactScalar.FromSymbol("m00")` 会被解析成 `m^00`（m 的 00 次方），
   应使用不含数字的单字母名（如 `u`、`v`、`w`）。
3. **复数判零不能用 `VerifyStrictZero`**：其 Approx 门控对复数不可靠（如 i² 的 Approx 是 0 而非 −1），
   复数/符号表达式判零须直接走符号通道（`Exact.Simplify().Equals(0)`）。
4. **`Entity.Set` 的枚举**：`MathS.SolveEquation` 返回的 `Entity.Set` 的 `GetEnumerator` 是显式接口实现，
   需显式转 `IEnumerable<Entity>` 才能遍历。

**顺手的地方（比主线舒服）**

- 结构层 `GeometryLens` 让"度量"变成显式外挂：内积用 `( |u|²+|v|²−|u−v|² )/2`，**全程无开方**；
- 切线用对偶二次型 `lᵀC*l=0`，不用解判别式；
- 曲线系（pencil）消元就是两个 `BilinearForm3` 的线性组合，非常直接；
- 射影/仿射/度量的前提在类型上可见（`BilinearForm3` vs `DualBilinearForm3` vs `GeometryLens`）。

**摩擦点（G1 之前必须补或承认）**

1. **没有圆锥曲线∩圆锥曲线**：本题靠手工曲线系消元 + 解一元二次；一般情形需要 resultants/消元层；
2. **交点有限/无穷远需要手动筛选**：直线与双曲线在渐近线方向平行时返回一个无穷远点，需自己按 W 过滤；
3. **表达式不化简/不可读**：(3) 的 N 与 OM·ON 的中间精确式巨大（打印几乎不可读），而主线有 `Derivation/ProofNarrator` 与化简策略；
4. **不等式/序结构缺席**：分段条件 |x|>x_A、值域 (6+2√5,∞)、可达性，仍必须由主线的 RealSets/Z3/证书层承担；
5. **没有解释层**：本 spike 只能打印结论，不能生成"引理链"。

**G0 判断**：Subspace 表示**能承载**这道题的射影/仿射/度量内容，且结构层让"前提"更可见；但它目前只覆盖"等式/关联/度量"片段，**不等式与解释层仍必须来自主线**。因此"完全替换"可行，但 G1 的前提是：先补 1（消元/交点）、3（化简/呈现），并把 4、5 作为架构边界而非缺口。
