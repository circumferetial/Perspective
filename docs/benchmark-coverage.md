## 已知空洞

| 空洞 | 会撞到什么 |
|---|---|
| 旋转 conic | `ConicFeatures` 直接失败（只支持 `Q01=0`） |
| 一般 conic–conic 求交 | 没有 API；目前只有线 conic 和圆交圆 |
| 切线从圆内点出发 | `TangentsFromPoint` 返回 0 切点，需调用方处理 |
| 有理函数区间/极点 | `IntervalRange` v1 不支持 |
| 三角函数不等式 | 没有层；高难题 2 属于这类 |
| 完整 PGL(2) 群作用 | 只有 `ConicFrame` 单次/复合 |
| 3D / 线几何 | 明确不接 |

## 已验证缺口（V1.0 不编码）

这三道题已核对答案，但**不属于 V1.0 的编码范围**：

| 题 | 结论 | 缺口 |
|---|---|---|
| A 旋转 conic | 中心 \((1,-1)\)，标准形 \(\frac{x'^2}{9}+\frac{y'^2}{4}=1\)，\(e=\sqrt5/3\)，焦点/准线正确 | `ConicFeatures` 只支持 `Q01=0`；需矩阵旋转/对角化 |
| B 椭圆 ∩ 抛物线 | 四个交点与共圆圆心/半径正确 | 没有一般 conic–conic 求交；只有线 conic 和圆交圆 |
| C 双曲线向量内积范围 | \((-\infty,-2-2\sqrt3]\cup(10-4\sqrt2,+\infty)\) 正确 | `IntervalRange` 不支持有理函数/极点 |

处理：

- A 可在 V1.1 用**结构化旋转**补，不手算展开；
- B 属于代数求解层，不塞进 `Subspace`；
- C 属于分析/值域层，不塞进 `Subspace`。

## 处理规则

1. 新 benchmark 先写期望结论；
2. 用现有 API 编码；
3. 若刚好撞空洞：
   - 要么补**最小** helper；
   - 要么把 benchmark 标记为“暂缺”，不伪装通过；
4. 补完后回填本表。

## 结论

当前覆盖的是**代表性样本**，不是题库全集。  
COV-1/2/3 用来补三个最明显的洞；再往后应优先补“会撞缺口”的题，而不是同类题。
